חיבור ל-GitHub

כדי שכפתור "פרסום" יעלה את השינויים ישר לאתר, צריך "מפתח" חד-פעמי מ-GitHub. עושים את זה פעם אחת בלבד:

  1. פותחים את הדף ליצירת מפתח ב-GitHub.
  2. בשם כותבים "עורך האתר", ובתוקף בוחרים שנה (או ללא תפוגה).
  3. ב-Repository access בוחרים Only select repositories ← amitsigawi-site.
  4. ב-Permissions ← Repository permissions ← Contents בוחרים Read and write.
  5. לוחצים Generate token, מעתיקים את המפתח ומדביקים כאן:

המפתח נשמר רק בדפדפן הזה, במחשב הזה. בלי מפתח אפשר עדיין לערוך – והכפתור יוריד את הקבצים להעלאה ידנית.
